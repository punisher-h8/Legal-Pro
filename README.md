# LegalVault Pro — Python / Windows EXE

منظومة التحقيقات والكفالات والدعاوى والنزاهة ووحدة المتابعة.

## ما الذي تم تحويله؟

هذا مشروع **Python لتشغيل وتغليف المنظومة الحالية كتطبيق Windows EXE**.
تتولى Python الخادم المحلي ونافذة التشغيل ومجلد ملف المتصفح الدائم.
تبقى الشاشات والمنطق الحالي بصيغة HTML/JavaScript داخل `web/LegalVault-Pro.html`؛
لم تُعَد كتابة آلاف أسطر الأعمال إلى Python، ولم تُغيَّر حقول الإدخال.
هذا يحافظ على شكل المنظومة وملفات النسخ الاحتياطي الحالية.

## تشغيل EXE

1. افتح `LegalVault-Pro.exe` على Windows 10/11 بنواة 64 بت. لا يلزم تثبيت Python للمستخدم النهائي.
2. يتطلب وجود Microsoft Edge أو Chrome أو Brave. تُفتح المنظومة في نافذة تطبيق باستخدام المتصفح المثبت.
3. إذا ظهرت رسالة أن المنفذ 8080 مستخدم، أوقف خادم PowerShell القديم باستخدام Ctrl+C أو أغلق النسخة الأخرى، ثم أعد تشغيل التطبيق.
4. اترك نافذة تشغيل LegalVault Pro مفتوحة أثناء العمل. الإغلاق منها يوقف الخادم ولا يحذف البيانات.
5. في أول استخدام اختر المسؤول الرئيسي، واستخدم الرمز الأولي الظاهر في الواجهة، ثم عيّن رمزك واحفظ رمز الاسترداد.

## مكان البيانات

ملف المتصفح الخاص بالتطبيق موجود في:

```text
%LOCALAPPDATA%\LegalVaultPro\BrowserData
```

تُحفظ السجلات في IndexedDB وLocalStorage داخل هذا الملف الدائم على القرص.
ليست قاعدة SQLite أو ملفات JSON منفصلة لكل سجل. لا تُحفظ البيانات داخل EXE،
ولا يؤدي استبدال EXE وحده إلى نقل البيانات أو حذفها. لا تمسح مجلد BrowserData.
استخدم النسخ الشامل من داخل المنظومة لحفظ نسخة قابلة للاستعادة؛ لا تنسخ ملف المتصفح أثناء تشغيله.

## نقل البيانات القديمة

ملف التطبيق الجديد يستخدم ملف متصفح مستقل. لن يقرأ بيانات Brave القديمة تلقائيًا.

1. افتح الصفحة القديمة في المتصفح الذي يحتوي بياناتك.
2. سجّل الدخول كمسؤول واختر «نسخة محلية شاملة» واحفظ الملف.
3. افتح EXE، وسجّل الدخول كمسؤول، ثم اختر «استعادة من ملف» وحدد النسخة.
4. أدخل عبارة تشفير النسخة إن كانت مشفرة، ثم تحقق من أعداد السجلات والمرفقات في الشعب الثلاث.
5. احتفظ بالصفحة القديمة ونسختها حتى تتأكد من نجاح النقل.

## Google Drive — جميع الشعب والوحدات

الخادم يعمل على `http://localhost:8080` ومقيد بالجهاز المحلي فقط.
لا يفتح منافذ للشبكة ولا يغير جدار الحماية.

1. فعّل Google Drive API وأنشئ OAuth Client من نوع Web application في مشروعك.
2. سجّل `http://localhost:8080` ضمن Authorized JavaScript origins.
3. إذا كان مشروعك في Testing، أضف حسابك إلى Test users.
4. من المسؤول الرئيسي افتح «النسخ وGoogle Drive — جميع الشعب والوحدات».
5. أدخل Client ID وعبارة تشفير من 12 حرفًا على الأقل ثم احفظ الإعداد.
6. اضغط اتصال، واختر حسابك وراجع الصلاحية المطلوبة. قد تحتاج ضغطة ثانية بعد تحميل خدمة Google.
7. اضغط «نسخ جميع الشعب إلى Drive» وتحقق من رسالة النجاح وظهور النسخة.

لا يُضمَّن Client Secret أو كلمة مرور أو رمز وصول داخل المصدر.
الرمز السحابي وعبارة التشفير مؤقتان للجلسة؛ احفظ عبارة التشفير خارج البرنامج.
النسخ السحابي ليس تحريرًا جماعيًا ولا يعمل عند إغلاق البرنامج.
التحقق الحقيقي من اتصال حسابك ونقل بياناتك واختبار استعادتها لم يُنفّذ ضمن بناء EXE.
الصلاحيات الحالية على مستوى الواجهة المحلية؛ ليست حماية خادم متعدد المستخدمين ضد مستخدم يملك تحكمًا كاملًا بالجهاز.

## تشغيل المصدر

```powershell
python app.py
```

يتطلب Python على Windows مع tkinter (متوفر عادة في مثبت Python الرسمي).

## بناء EXE محليًا

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe build.py
```

الناتج: `dist/LegalVault-Pro.exe`.
PyInstaller يضم Python والواجهة داخل الملف؛ بيانات التشغيل تبقى خارجه.
مرجع أداة البناء: https://pyinstaller.org/en/stable/usage.html

## بناء EXE على GitHub

ارفع ملفات المصدر كما هي إلى جذر المستودع، بما فيها `.github/workflows/windows-exe.yml`.
من تبويب **Actions** اختر **Build Windows EXE** ثم **Run workflow**.
بعد نجاح المهمة نزّل **LegalVault-Pro-Windows** من Artifacts وفك ضغطه.
لا ترفع ملفات النسخ الاحتياطي أو مجلد BrowserData أو كلمات المرور إلى المستودع.

## الاختبارات وحدودها

الاختبارات تشمل الموارد المدمجة، وجود الشعب الثلاث، حماية مسارات الخادم، ورفض Host غير صحيح.
يمكن فحص EXE دون فتح نافذة عبر:

```powershell
.\dist\LegalVault-Pro.exe --self-test --report self-test-exe.json
```

اختبار الموارد لا يثبت نجاح Google OAuth ولا سلامة نقل بيانات حقيقية.
ملف EXE غير موقّع بشهادة ناشر. توقيع الإصدار يحتاج شهادة يملكها صاحب المشروع.
